# 漫剧 Agent 客户端

参考 ChatGPT/Codex 桌面客户端信息架构实现的 Tauri 2 MVP。产品以“对话即任务”为核心：新对话可以独立使用，也可以绑定一个本地文件夹作为项目上下文。

## 已实现

- 默认空工作区，不预置任何演示业务数据
- 新对话即新任务，不存在“新建项目”流程
- 通过真实文件夹选择器为当前任务绑定项目上下文
- 同一文件夹下的多轮任务在左侧自动归组
- 未绑定文件夹的任务显示在“最近”
- Ctrl+K 搜索真实任务、项目文件夹和资源
- 中间固定为 Agent 对话，输入框上方可随时选择项目文件夹
- 右侧展示当前项目文件夹的真实文件与生成任务
- 右侧栏折叠动画、中央区域同步扩展和拖拽调宽
- 右栏宽度本地记忆，双击分隔条恢复默认宽度
- 设置使用独立模态窗口，不占用对话区域
- 对话、生图、视频三类模型与 API 独立配置
- Base URL、API Key、模型 ID、请求路径和自定义请求头配置
- OpenAI 兼容模型连接测试与真实 Chat Completions 调用
- 未配置模型时明确阻止发送，不生成模拟回复
- TXT/Markdown 小说导入、本地保存和文本预览
- 项目文件夹、任务、资源与配置的本地持久化
- 统一的输入框、自定义下拉框、弹窗、通知和错误提示样式
- 页面、标签、侧栏、下拉菜单、弹窗和通知具备过渡动画
- Tauri 自定义窗口栏、窗口拖动、最小化、最大化和关闭
- React/Vite 热更新

## 技术栈

- Tauri 2
- React 19
- TypeScript
- Vite
- Lucide Icons

## 本地开发

```bash
npm install
npm run tauri dev
```

仅查看 Web 界面：

```bash
npm run dev
```

## 构建

```bash
npm run build
npm run tauri build -- --debug
```

调试版程序生成在：

```text
src-tauri/target/debug/manju-agent-client.exe
```

## 当前边界

对话模型已支持 OpenAI 兼容接口。生图和视频模型已经有独立配置入口，实际生成请求和任务调度需要根据供应商协议继续接入。当前 API Key 保存在本机 WebView 存储中，正式发布前应迁移到系统凭据存储。
